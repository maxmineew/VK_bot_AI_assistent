# VK-бот записи в фокус-группу

Бот для сообщества ВКонтакте: гость по QR-коду заходит в диалог, бот за 4 шага собирает
заявку и мгновенно уведомляет владельца в Telegram + дописывает строку в CSV.

**Сценарий:** приветствие с кнопками → «Что за продукт?» (описание) / «Хочу в фокус-группу» →
ниша (кнопки) → боль (кнопки или «✏️ Другое» — свободный текст) → удобное время → финал.
Повторное сообщение после финала снова вызывает приветствие.

## Возможности

- Long Poll VK (публичный сервер и вебхук не нужны — только исходящие соединения)
- Машина состояний: диалоги переживают перезапуск (`vk_bot_state.json`)
- Заявки: пуш-сводка в Telegram + дописывание в `заявки_фокус-группа.csv` (utf-8-sig, `;` —
  открывается в Excel как план обзвона)
- Метка источника `ref` из deep-link ссылки вида `vk.me/СОБЩЕСТВО?ref=netw1911`
- Команда `/reset` (только для ADMIN_VK_ID) — сброс своего диалога для тестов
- Повторы при сетевых сбоях, лог в консоль + `vk_bot.log`
- `--selftest` — полный прогон сценария без VK и токенов (mock-отправка)

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env   # Windows: copy .env.example .env
# заполнить .env (см. комментарии внутри)
python vk_focus_group_bot.py
```

Проверка логики без токенов:

```bash
python vk_focus_group_bot.py --selftest
```

Токены читаются из `.env`, а при его отсутствии — из переменных окружения
`VK_TOKEN`, `TG_TOKEN`, `TG_CHAT`, `ADMIN_VK_ID` (так их задаёт хостинг-панель).

## Подготовка сообщества ВК

1. Управление → Работа с API → **Long Poll API** — включить, событие «Новые сообщения».
2. Управление → Работа с API → Ключи доступа — ключ с правом **«Сообщения»** → `VK_TOKEN`.
3. Управление → Сообщения → включить; **«Возможности ботов» → «Разрешены»**
   (иначе VK отвечает ошибкой 912). Штатное приветствие/автоответы — выключить.

## Деплой на хостинг (бот 24/7)

Подходит любой хостинг длительных Python-процессов (bothost.ru и т.п.):
файл бота + `requirements.txt`, токены — в env-переменных панели, запуск
`python vk_focus_group_bot.py`.

⚠️ Запускать **один экземпляр**: VK отдаёт каждое сообщение только одному
Long Poll-потребителю — два работающих бота будут перехватывать сообщения друг у друга.

## Безопасность

`.env`, CSV заявок, state-файл и логи — в `.gitignore`, в репозиторий не попадают.
Токен сообщества скомпрометирован → перевыпустите ключ в Управление → Работа с API.
